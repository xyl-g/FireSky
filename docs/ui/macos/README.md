# macOS 界面图册

2026-11-28：macOS 与 iOS 分别作为桌面和移动端 UI 基准；Windows 向 macOS 对齐，Android 向 iOS 对齐。保留平台原生控件与操作习惯。

完整截图、图库索引和交互证据位于本机忽略目录，不随源码发布；当前文档记录截图范围、操作与验收边界。

具体构建、截图和实际点击范围见 [验收记录](VALIDATION.zh-CN.md)；图册页面的浏览器交互尚未点验。

## 参考顺序

1. `current/`：本轮源码生成的当前界面。覆盖单点概览、大气剖面、诊断、逐时台账、区域、实况、设置三个分类、数据管理、空历史、初次使用、单模式失败及旧参数状态；均有浅色和深色，概览与剖面另有 1120×720 窄窗。
2. `interactions/`：人工点击验证的界面和操作记录，以验收记录为准。
3. `archive/`：以前的视觉矩阵、预检、提醒、导出、日历、大文本与历史回放证据。`navigation-attempt/` 是已放弃的布局试验，其他历史图也不能覆盖当前图。
4. `references/`：用户提供的更新弹窗、桌面与设置设计灵感，不是 FireSky 已实现界面。参考其层级、分组、留白与控件对齐。
5. `feedback/`：用户报告的下载重试、保留清理和剖面尺寸问题，用于复现与验收，不能作为目标设计。

`sources.json` 保存历史图和用户附件的原始来源、分类和原文件 SHA-256；`current/manifest.json` 保存本次截图的源码哈希、提交、窗口尺寸、主题、场景开关和图片哈希；`catalog.json` 是整份图册的图片清单及归档文件哈希。PNG 仅重压缩数据流，逐字节验证解压数据一致，不改变像素、元数据、尺寸或裁切。

## 当前边界

- 当前截图使用明确标识为“非真实预测”的合成数据，网络被禁止；图表形状、云属代理分数和结果数字用于展示状态，不是真实预报或云属观测验收。地图可能显示系统已缓存底图。
- 大气剖面采用图表优先布局：详细页保留紧凑 GFS/EC 指数、最佳时刻和独立失败状态；旧参数提示继续可见。诊断数值、云属候选和目标详情位于图后，完整模式来源与时间轴在概览页。
- 云属候选来自报告级 `cloud_genus_proxy`；网格只有高/中/低压力族时仍按压力族标注，不把它当作卷云或高积云的逐点识别。
- 当前图库覆盖主要可见页面和状态，不等于全应用 UI 验收完成；真实下载、通知送达、完整 VoiceOver 与英文诊断翻译仍有验收缺口。历史提醒图为权限夹具，空历史不代表任务恢复验收。
- 下载失败重试、保留策略触发与本地检查性能仍是待处理项，见 [交接文档 §20.16](../../MACOS_LIQUID_GLASS_UX_HANDOFF.zh-CN.md)。局域网 HTTP / Cloudflare Tunnel 和移动远端区域能力继续留在规划。

## 平台对齐目标

| 平台 | 对齐目标 | 单独验收 |
|---|---|---|
| macOS | 桌面基准：专业工作流、剖面缩放、浅/深主题与窄窗 | 桌面布局、键盘操作和状态语义 |
| Windows | 靠近 macOS 的信息结构、颜色语义、内容密度和操作顺序 | WinUI 控件、键盘导航、窗口尺寸、引擎连接 |
| iOS | 移动基准：原生导航、触控优先、系统动态字号 | 大字布局、滚动、VoiceOver 和主要操作 |
| Android | 靠近 iOS 的信息层级、状态和触控流程 | Compose 控件、系统字号、返回/导航与主要操作 |

移植时保持专业指标、单位、缺测/失败/旧结果含义、GFS/EC 独立性与操作顺序。不要逐像素复制 macOS 窗口装饰、SF Symbols 或鼠标目标尺寸。第三方参考图中的账号、品牌和装饰不进入产品。

## 重新生成

本机需要 Node.js 22.15 或更新版本（使用 `node:zlib.crc32`）、完整 Xcode 和可运行的 macOS FireSky bundle。默认只读取 `dist/native-macos/FireSky.app` 中的运行资源；源码按当前工作区重新编译。每次截图使用独立临时工作区，不读取用户预测缓存。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer node scripts/capture_macos_ui.mjs
node scripts/index_macos_ui.mjs
```

使用其他 bundle 时设置 `FIRESKY_NATIVE_APP=/absolute/path/FireSky.app`。可在捕获脚本后增加输出目录参数，先生成候选图再人工检查。脚本成功只表示图片生成完成，视觉结论由人工检查与交互记录补充。刷新后保留有价值的旧证据并更新来源，不混用旧图冒充新版本。

索引刷新默认只读图片并更新清单，不重复压缩全部历史图。新增手动截图需要无损压缩时执行 `node scripts/index_macos_ui.mjs --compress`；当前矩阵已在捕获时压缩。

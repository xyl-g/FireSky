# macOS UI 验收记录

日期：2026-11-24（续 2026-11-23）。分支：`feat/macos-liquid-glass-ui`。本轮以 macOS 为唯一当前 UI 基准，Windows 后续参考，iOS / Android 暂缓扩展。

## 变更范围

- **2026-11-24 窗口与格局优化**：主窗口启用 `.windowStyle(.hiddenTitleBar)`，统一侧栏与 56pt 顶栏（含快速外观切换与更新/离线状态胶囊）；修复空历史页头部垂直居中偏移缺陷；首次无结果空态移除十余张空占位指标卡；分析页签改为左对齐胶囊条并与 `GFS / EC` 模型切换同行对齐；1120×720 窄窗下左侧参数列完整展示不裁切。
- **2026-11-24 设置、更新弹层与反馈修复**：设置页取消嵌套双侧栏，改为顶部胶囊分类切换与 820pt 居中图标行卡片布局，补齐语言切换与版本兜底文案；新增独立 `UpdateSheetView` 软件更新弹层并纳入图册；地形下载确认移除误用红色 `.destructive` 样式并增加失败瓦片重试入口；保留策略区补充规则计数与手动清理直达入口。
- 详细结果页使用紧凑 GFS / EC 摘要，保留指数、最佳时刻、独立失败和旧参数提示；完整摘要与时间轴在概览页。
- 大气剖面先展示图面，再展示诊断数值、报告级云属代理和目标详情；移除重复标题及嵌套边框。
- 图面随窗口宽度调整，支持 100% 至 250% 缩放、横向滚动和适配窗口；字号最低 10pt，末端距离标签向内对齐。
- 真实点击发现 250% 下小数高度标签左侧裁切，已改为按实际文字测量轴边距。
- 缩放按钮分别提供可访问性名称；图面暴露 Increment / Decrement 操作；摘要读出最佳时刻的实际值。辅助字号下紧凑摘要按单列排列。

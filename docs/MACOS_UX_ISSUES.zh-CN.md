# FireSky macOS 客户端交互体验问题清单

分析日期：2026-11-20 · 对象：v1.0.0（main `352e409`）SwiftUI 原生客户端

## 方法与范围

- 证据来源：`apps/macos/Sources/FireSkyNative/` 源码逐文件审查，辅以一段真机实测
  （v1.0.0 安装版，辅助功能树 + 截图）。应用户要求，实测已停止，此后全部为源码分析。
- 每条问题标注 **实测**（在运行中的 app 里直接观察到）或 **代码级**（仅由源码推断，
  未在运行中复现）。行号为 2026-11-20 主分支快照，后续提交可能漂移。
- 本文是问题清单，不是改动授权；所有建议均未实施。
- 与 `docs/MACOS_UI_BASELINE.zh-CN.md` 的关系：基线中的硬约束（预检显式确认、
  GFS/EC 独立、缺失不补零、失败/取消不覆盖上一份有效结果、macOS 为跨平台基准）
  全部保留。下文建议若触及这些约束，均以满足约束的方式提出（见问题 31）。

严重度定义：

- **P0 信任与正确性**：展示内容与事实不符，或迫使用户做出错误判断。
- **P1 高摩擦**：日常主流程被显著拖慢、锁死或引入数据丢失风险。
- **P2 惯例与打磨**：违背 macOS 平台惯例或可读性不足，长期累积疲劳。

## P0 信任与正确性

### 1. 恢复历史结果后，标题与表单仍是当前参数（代码级）

- 现象：从历史恢复一份旧结果，页面顶部标题和左侧表单仍显示当前的地点/日期/现象，
  恢复来的结果被贴上错误标签。
- 证据：`Store.swift:840` `restoreTaskResult` 只写 `result/resultKind/page/selectedModel`，
  不回填 `name/lat/lon/date/phenomenon`；标题读 `store.name`/`targetDateLabel`
  （`Workbench.swift:401` 单点、`:2487` 实况）。对照组：重试路径的
  `applyRetryPayload`（`Store.swift:880` 起）会完整回填表单参数，恢复路径没有复用。
- 为何反人性：用户看到“杭州 · 今天 晚霞”的标题，实际内容可能是上周北京的结果，
  直接误导判读，也违背“结果可追溯”的产品承诺。
- 建议：恢复时同步回填该任务的参数（复用 `applyRetryPayload`），或在结果区显著标注
  “历史结果 · 参数与当前表单不一致”。

### 2. 未预测时摘要显示“无可烧目标云”（实测）

- 现象：冷启动、尚未运行任何预测，摘要条已显示“无可烧目标云”——一个科学结论
  被当作空态文案。
- 证据：`Workbench.swift:446` 把 `report?[...]`（nil）传入 `familyLabel`；
  `Workbench.swift:3120-3125` 的 default 分支返回“无可烧目标云”。
- 为何反人性：把“没有数据”渲染成“预测结论为无”，用户会误以为 app 已经算过并
  给出否定答案，损害对后续真实结论的信任。
- 建议：`report == nil` 时显示“未预测”或 `—`；结论性文案只在有结果时出现。

### 3. 任何参数变化立即清空已有结果（代码级）

- 现象：改坐标、海拔、时区、日期、现象、区域、EC 数据源，甚至地图选点，
  都会立刻 `result = nil`，右侧结果区瞬间消失。
- 证据：`Store.swift:35-45` 各参数 `didSet`；`:145-150` `ecmwfSource`；
  `:163-164` `selectedRegions/customRegion`；`:361-363` 地图选点。
- 为何反人性：预测类产品最常见的动作是“改一个参数，和上一份结果对比”。
  当前行为让对比不可能：想看看明天，就得先失去今天的结果；在设置里换个
  EC 源也会顺手毁掉当前结果。
- 建议：保留旧结果并加“参数已变更，结果对应旧参数”徽标 + 一键重算；
  这与基线“失败/取消不覆盖有效结果”的精神一致，只是把保护扩展到参数变更。

### 4. 历史时间戳裸 UTC 字符串（实测）

- 现象：历史列表与事件流直接显示 `2026-11-20T02:40:01.023Z` 这类 ISO 串；
  本地上午 10:40 的任务显示为 02:40。
- 证据：`TaskHistory.swift:239` `Text(item.createdAtUTC)`、`:295` `Text(event.atUTC)`。
  设置页已有本地化转换 `dataSyncTimeText`（`DialogViews.swift:486`），历史页未复用。
- 为何反人性：用户要心算时区才能判断“这是不是刚才那次”，时间恰恰是历史页
  最核心的扫读字段。
- 建议：统一走本地时区格式化（复用 `dataSyncTimeText`），原始 UTC 放 help/次要行。

## P1 高摩擦

### 5. 全局 busy 静默锁死整个应用（代码级）

- 现象：任何任务进行中（包括轻量地名搜索），侧栏切页、⌘1-4、设置入口、
  全部表单都被禁用，且没有禁用外观或提示——点了没反应。
- 证据：`Workbench.swift:100`、`:120` `if !store.busy { store.page = ... }`；
  `FireSkyApp.swift:20-27` 菜单同逻辑；`Store.swift:341-344` `search()` 也置全局
  `busy`；表单 `.disabled(store.busy)`（`Workbench.swift:258`、`:310`、`:2139`、
  `:2152`；`DialogViews.swift:401` 整个设置页）。
- 为何反人性：“点了没反应”是最令人困惑的反馈；一次一秒的地名搜索不该锁住
  全 app；预测进行中用户恰恰想去数据页看下载进度，却被挡在门外。
- 建议：busy 细分为任务级状态；任务中允许切页与只读浏览；确需禁用的控件给出
  禁用外观 + help 说明原因。

### 6. 收藏只能加不能管，空收藏是空白面板（实测空面板）

- 现象：收藏列表只有“点击应用”按钮，无删除/重命名/排序；空收藏时是一块
  完全空白的面板，无任何引导；地图选点统一命名“地图选点”，多个收藏无法区分。
- 证据：`Workbench.swift:232-240` 纯按钮列表；`Store.swift:1579-1584`
  `starLocation` 仅去重追加；`Store.swift:361` 固定命名。
- 为何反人性：收藏是高频入口，却是“只进不出”的杂物堆；加错的地点永远删不掉，
  三个“地图选点”只能靠猜。
- 建议：右键菜单（重命名/删除）、空态引导文案、地图选点保存时允许命名或
  反向地理编码。

### 7. 无会话持久化，每次启动从零开始（代码级 + 实测初始态）

- 现象：每次启动都回到杭州/今天/晚霞；上次的地点、日期、结果都不恢复，
  想看昨天的结果要手动走 数据 → 历史 → 恢复。
- 证据：`Store.swift:238` 起 `init` 只恢复 workspace 等配置；`:35-41` 地点/日期/
  现象为硬编码默认值。收藏（`:1584`）、EC 源（`:147`）、外观（`:1119`）都有
  持久化，唯独核心工作会话没有。
- 为何反人性：产品的日常场景是“每天看我这个点位的晚霞”，现在每天第一次
  打开都要重新输地点、选日期，把最高频动作的成本放大。
- 建议：持久化上次地点/日期/现象并启动恢复；可选自动恢复上一份已发布结果
  （带“历史结果”标注，与问题 1 的修复配套）。

### 8. CAMS Token 保存失败即清空输入（代码级）

- 现象：点保存后输入框立刻清空；若异步保存失败，用户得重新找 token 再贴一遍。
- 证据：`Store.swift:1489-1494` 在异步保存发起前就 `camsKeyDraft = ""`。
- 为何反人性：token 是长随机串，用户往往没有留底；“失败即丢输入”是经典反模式。
- 建议：保存成功后再清空；失败保留草稿并显示错误。

### 9. CAMS Key 明文落盘（代码级）

- 现象：设置页自述“仅以明文保存在本机配置文件，文件权限 0600”。
- 证据：`DialogViews.swift:220`。
- 为何反人性（风险）：macOS 用户预期凭据进钥匙串；明文文件可能被备份、
  同步工具或其他进程顺走。0600 是缓解，不是答案。
- 建议：迁移 Keychain（引擎读配置的方式需配套改造，属跨层任务）；
  短期至少提供“删除已保存 Key”入口。

### 10. 数据目录可直改、无确认即生效（代码级）

- 现象：数据目录是裸 TextField；改动后连接成功即持久化新目录，旧缓存与
  历史从界面“消失”，无警告、无迁移提示。
- 证据：`DialogViews.swift:382`；`Store.swift:332-333` 连接成功后持久化。
- 为何反人性：用户会以为数据丢了；一个手误就把工作区切到空目录。
- 建议：改用目录选择面板；切换前显式确认并说明“旧目录数据仍在磁盘，
  只是不再显示”。

### 11. 后台助手卸载无确认（代码级）

- 现象：点“卸载”直接移除 launchd 后台同步助手，一步到位。
- 证据：`DialogViews.swift:357` → `Store.swift:1465` `uninstallHelper`。
- 为何反人性：删一条历史记录都有确认框（`TaskHistory.swift:206`），
  卸载系统级后台服务反而没有；误触即静默失去后台同步。
- 建议：加确认框，说明影响（后台同步将停止，可重新安装）。

### 12. 任务进行中退出无确认（代码级）

- 现象：预测/下载进行中 ⌘Q，任务被静默取消。
- 证据：`FireSkyApp.swift:47` `applicationWillTerminate` 直接 `shutdown()`。
- 为何反人性：可能丢掉跑了几分钟的下载；macOS 惯例是对进行中任务给出
  “仍在运行，确定退出？”确认。
- 建议：busy 时拦截终止并确认（`reply(toApplicationShouldTerminate:)`）。

### 13. 历史满屏匿名“任务 · 任务”行（实测）

- 现象：历史列表大量“任务 · 任务”标题，看不出是什么；实为后台数据同步轮次。
- 证据：`TaskHistory.swift:79-88` `methodTitle` default 返回“任务”；引擎把
  `data_sync_run/tick` 统一记为 `data_sync`（`engine/src/desktop_runtime.rs:427-431`），
  Swift 侧没有该标签的映射。
- 为何反人性：历史页的价值是“看懂发生过什么”，匿名行把它变成噪音，
  用户自己的任务被淹没。
- 建议：`data_sync` 映射为“后台同步”并带轮次摘要；默认折叠后台轮次，
  可展开。

### 14. 恢复/重试图标易混，重试无确认（代码级）

- 现象：↩（恢复结果）与 ↻（恢复参数并重新检查）两个相邻圆形箭头图标，
  语义接近；点后者立即进入数据检查流程。
- 证据：`TaskHistory.swift:255-266`；重试经 `restoreTaskParameters`
  （`Store.swift:830-838`）回填参数后立即 `beginCheck()`。
- 为何反人性：图标相邻且形似，误点率高；“重试”隐含网络/计算副作用，
  却无任何确认或成本提示。
- 建议：图标 + 文字区分，或换用差异更大的符号；重试前轻量确认
  “将重新检查数据，可能触发下载”。

### 15. metadataReady 门槛报错，解法开关藏得深（代码级）

- 现象：开始预测报“请先获取海拔与时区，或手动确认位置数据”，但“手动确认”
  开关藏在折叠的“编辑坐标”面板里；地图选点后 `metadataReady` 重置为 false，
  离线元数据获取失败时用户被卡死在找不到开关的路上。
- 证据：`Store.swift:477-480` 报错；`Workbench.swift:289` 折叠入口；
  `Store.swift:362` 选点重置。
- 为何反人性：错误文案指向一个用户找不到的操作，等于没有给出解法。
- 建议：错误提示处直接附“手动确认位置数据”按钮，或自动展开坐标面板并
  高亮开关。

### 16. 台账宽表横向滚动，藏掉一半内容（代码级）

- 现象：单点逐时台账 15 列、最小宽 1284pt，最小窗口（1120pt）下内容区约
  600pt；横向滚动条被隐藏，也没有“右侧还有内容”的视觉提示。
- 证据：`Workbench.swift:1299` `ScrollView(.horizontal, showsIndicators: false)`、
  `:1313` `minWidth: 1284`；实况台账 `:2877` 同构。
- 为何反人性：用户以为看到了全部数据，实际一半列不可见；隐藏滚动条抹掉了
  唯一线索。
- 建议：显示滚动指示 + 右缘渐隐提示；时间列冻结、列宽自适应；提供列配置。

### 17. 区域页错误截断两行且读不全（代码级）

- 现象：区域页错误 `lineLimit(2)`，无 help、无 textSelection，长错误被拦腰截断。
- 证据：`Workbench.swift:2097-2099`；对照单点页 `:308` 支持文本选择、
  预检 `DialogViews.swift:55` 三行 + 可选择。
- 为何反人性：错误文案是用户自救的唯一线索，截断后既读不全也复制不了。
- 建议：与单点页对齐：textSelection + help 全文，或点击展开。

### 18. 滚轮被地图劫持，滚表单变成缩放（代码级）

- 现象：地图安装本地 scrollWheel 监听，指针悬在任何地图（包括表单内嵌
  176pt 小地图）上时，滚轮缩放地图而不是滚动页面。
- 证据：`ForecastMap.swift:300-312` 本地事件监听消费滚动增量；
  小地图 `Workbench.swift:228-230`。
- 为何反人性：滚动表单经过小地图时页面“卡住”、地图乱缩放；macOS 惯例是
  地图类视图用修饰键 + 滚轮或聚焦后才缩放。
- 建议：⌘/Option + 滚轮或地图聚焦时才缩放，默认滚轮交还外层滚动。

## P2 惯例与打磨

### 19. 字体整体过小（代码级）

- 现象：全局基础字号 12pt，状态栏 9pt，多处指标卡标题与剖面轴标签 8pt。
- 证据：`Workbench.swift:47`（12pt）、`:169`（9pt）、`:792`/`:1910`/`:2454`/`:2754`
  （8pt 标题）、`:1656`/`:1667`/`:1691`/`:1743`/`:2793`/`:2802`（8pt Canvas 标签）。
- 为何反人性：8pt 低于 macOS 可读下限（正文惯例 13pt、次要 11pt），
  高分屏上仍费眼；信息密度不该以牺牲可读性换取。
- 建议：正文 ≥12pt、次要 ≥10pt、轴标签 ≥9pt；用 Dynamic Type 语义字号。

### 20. 自绘日历：过去日期全可选、只能逐月翻（实测过去日期可选）

- 现象：日历里所有过去日期都可点；翻月只有左右箭头，没有年份跳转；
  自绘控件替代了系统日期选择器。
- 证据：`Workbench.swift:345-390` 自绘月历，`:352-356` 仅逐月；
  `ObservationDate.swift:56` `moved(_ months:)`。
- 为何反人性：预报产品选过去日期多半是误操作；引擎对过去日期的行为
  **未验证**（可能报错或空转），UI 至少应给出约束或提示。
- 建议：过去日期置灰或标注；加年份快捷跳转；评估改用 NSDatePicker。

### 21. 菜单与命名不合惯例（代码级）

- 现象：页面导航 ⌘1-4 放在“文件”菜单（替换新建项的位置）；侧栏叫
  “实况观测”，菜单和页面标题叫“卫星实况”；开始预测没有 ⌘R/⌘↩，
  取消任务没有 ⌘.。
- 证据：`FireSkyApp.swift:19-27`；`Store.swift:13` vs `FireSkyApp.swift:24`、
  `Workbench.swift:2493`；全仓 keyboardShortcut 仅预检/地图/日历
  （`DialogViews.swift:65-81` 等）。
- 为何反人性：⌘1-4 惯例属于“显示/窗口”类菜单；同一页面两个名字增加
  心智负担；高频动作缺快捷键，与 macOS 肌肉记忆脱节。
- 建议：导航移入 View 菜单（CommandGroup(after: .toolbar) 或自定菜单）；
  统一命名；开始预测 ⌘↩、取消 ⌘.。

### 22. 禁用按钮不给原因（代码级）

- 现象：离线或 busy 时“开始预测”只降透明度，无 tooltip 解释为什么不能点。
- 证据：`Workbench.swift:159-160` `opacity(0.45)` + `.disabled`，无 help。
- 为何反人性：用户面对灰按钮只能猜；离线是常见状态，应直接告知
  “引擎离线，请先连接”。
- 建议：禁用态附 help 说明原因与恢复路径。

### 23. “重置”名不副实（代码级）

- 现象：重置按钮只把日期改回今天、现象改回晚霞，地点/坐标/区域不动。
- 证据：`Workbench.swift:277`。
- 为何反人性：用户预期“重置”恢复整组参数；实际只重置两项，语义落差
  会在排错时误导（“我重置过了怎么还是不对”）。
- 建议：改名“今天 · 晚霞”，或提供真正的整组重置。

### 24. 红点探测催办像错误徽标（实测）

- 现象：未完成下载探测时，“数据与下载”侧栏项挂 7px 红点。
- 证据：`Workbench.swift:107-109`。
- 为何反人性：红点在 macOS 语义里是错误/未读告警；一个“建议去做”的
  提醒被渲染成“出事了”，制造无谓焦虑。
- 建议：改用中性色提示或文案徽标；探测完成后自然消失（现有逻辑保留）。

### 25. CAMS 未配置时启动即模态弹窗（代码级）

- 现象：未配置 CAMS Key 时每次启动弹模态 alert。
- 证据：`Store.swift:324-329` 置 `showCAMSReminder`；`Workbench.swift:72` alert。
- 为何反人性：启动即被模态打断，且 CAMS 并非所有流程的必需项；
  本次实测因已配置未触发。
- 建议：改为页面内横幅提醒，附“去配置/不再提醒”。

### 26. 全局 error 串页泄漏（代码级）

- 现象：`store.error` 是单一全局字符串，同时渲染在单点、区域、数据清单、
  设置多处；一处操作的陈旧错误会挂在无关页面上。
- 证据：`Workbench.swift:308`、`:2097-2099`；`DialogViews.swift:55`、`:171`、
  `:398-399`。
- 为何反人性：用户在设置页看到一条预测错误，无法判断它属于谁、是否仍有效。
- 建议：错误按来源/页面归属展示，切页或新操作开始时清理无关错误。

### 27. 置信度口径两处不一致（代码级）

- 现象：单点页明确标注“输入支持度 · 非命中概率”，区域格点详情却直接显示
  “置信度 NN%”，无免责声明。
- 证据：`Workbench.swift:469` vs `:2435`。
- 为何反人性：同一数值两种口径，用户会把支持度当成命中概率做决策，
  这正是基线要求避免的误读。
- 建议：区域侧沿用同一口径文案与 help 说明。

### 28. 区域菜单不显当前选择（代码级）

- 现象：区域选择 Menu 的标签固定为“预测区域”，不显示已选区域；
  区域页也没有单点页的“今天/明天”快捷段。
- 证据：`Workbench.swift:2118-2120` 固定 Label；区域页仅 `WorkDateButton`
  （`:2142`）。
- 为何反人性：当前状态不可见，每次都要点开菜单确认；两页能力不对齐
  增加学习成本。
- 建议：Menu 标签显示当前选择摘要；区域页补齐日期快捷段。

### 29. 历史只取 100 条，事件面板藏在列表下方（代码级 + 实测布局）

- 现象：历史请求固定 limit 100，无分页/加载更多；任务事件面板在列表下方，
  嵌套 ScrollView，要看事件得先滚过整个列表。
- 证据：`Store.swift:708` `["limit": 100]`；`DialogViews.swift:103` +
  `TaskHistory.swift:187` 嵌套滚动。
- 为何反人性：重度用户的历史会被静默截断；“选中任务看事件”这一连贯动作
  被滚动割裂。
- 建议：分页或时间过滤；事件面板改为侧栏/下方固定分栏，选中即见。

### 30. 缓存无手动清理入口（代码级）

- 现象：数据清单页只能看，不能按数据集清理；保留策略只在成功 prepare 后
  生效；“在访达中打开”反而引导用户手删文件。
- 证据：`DialogViews.swift` InventoryView（`:103-175` 区域）无删除操作。
- 为何反人性：磁盘涨满时用户没有安全出口，只能去文件系统冒险，
  可能误删正在使用的缓存。
- 建议：提供按数据集/按时间的安全清理（走引擎 retention 接口），
  明示将释放的空间。

### 31. 预检双重弹窗（代码级；sheet 实测）

- 现象：预检 sheet 之上再叠一个 cycle-age confirmationDialog，两层确认。
- 证据：`DialogViews.swift:87` confirmationDialog 叠在预检 sheet
  （`Workbench.swift:60-61`）上。
- 为何反人性：连续两层打断拖慢主流程。注意：基线要求周期过旧必须显式
  确认，此条**不建议删除确认**。
- 建议：把周期过旧警示与确认合并进预检 sheet 内（醒目横幅 + 同一个
  “确定预测”按钮承载确认语义），保持显式确认不变。

### 32. 取消是协作式，无升级手段（代码级）

- 现象：取消后仅显示 9pt 小字“正在取消，等待当前阶段结束”，无已等待
  时长、无强制终止；UI 层对引擎调用也没有超时看门狗。
- 证据：`Store.swift:683-685`；状态字号 `Workbench.swift:169`；
  `EngineClient.swift`/`FFIEngineClient.swift` 未见调用级超时。
- 为何反人性：阶段卡住时“取消”看起来也失灵，用户唯一出路是强杀 app。
- 建议：显示等待时长；超过阈值提供“强制结束”；引擎调用加超时与
  可中断点（需引擎侧配合）。

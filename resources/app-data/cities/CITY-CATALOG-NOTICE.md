# China City Catalog Notice

`china-city-catalog.json` is a generated 695-city administrative-center
catalog. It is data, not FireSky source code, and is distributed with source
attribution metadata in the JSON file.

Sources:

- Administrative geometry and center coordinates:
  https://geo.datav.aliyun.com/areas_v3/bound/geojson
- 2026 administrative division reference:
  https://www.xzqh.org/show/china/2026/2026.html

The upstream sources do not provide a single SPDX license statement for this
derived catalog. The file therefore remains explicitly marked as
`license_status: "upstream-terms-not-specified"` in the application resource
manifest. Downstream redistributors must preserve this notice and verify the
current upstream terms before publishing a public package.
